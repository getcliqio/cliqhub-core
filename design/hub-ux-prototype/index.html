Getting started

Follow these instructions on your machine. Your default realm is already set up — you don’t need to create one. When you’re done, everything shows up here in Hub: daemons, runs, and logs.

Ready Default realm personal is yours. Open realm →
  1. 1

    Install the CLI

    One-time on this computer.

    curl -fsSL https://getcliq.io/cliq/install | bash
cliq --version
  2. 2

    Get a key and sign in

    Create a user token in Hub, then log the CLI into CliqHub.

    Create token then on your machine: 
    cliq login
cliq whoami
  3. 3

    Start the daemon

    The daemon is what actually runs teams. For Hub enrollment, mint a realm enroll token on your realm (already created), set CLIQ_DAEMON_TOKEN, then start.

    Mint realm token Daemons list 
    export CLIQ_API_URL=https://cliqhub.io
export CLIQ_DAEMON_TOKEN=cliq_dt_••••••••   # from realm → Realm tokens
cliq-daemon &
cliq daemon status
  4. 4

    Install a team and run it

    Pick something from Browse (e.g. @cliq/hello-world), install/assemble, then run.

    Browse teams My teams 
    mkdir ~/cliq-hello && cd ~/cliq-hello
cliq init
cliq assemble @cliq/hello-world
cliq run
  5. 5

    See it in Hub

    After the first run, come back here — no extra setup.

    • Daemon online under your realm Daemons →
    • Run status and history Runs →
    • Raw output / errors Logs →

Enroll daemon

Mint a realm token and start the daemon on a host. The token is scoped to one realm.

Host commands

export CLIQ_API_URL=https://cliqhub.io
export CLIQ_DAEMON_TOKEN=cliq_dt_••••••••
cliq-daemon start

What happens

  1. Mint cliq_dt_… for the realm.
  2. Set CLIQ_DAEMON_TOKEN and start.
  3. Daemon appears online after heartbeats.
