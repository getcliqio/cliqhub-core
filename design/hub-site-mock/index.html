Getting started

Three steps: run locally first, connect the CLI to Hub, then create and share your own realm.

Docs: Get started

Docs & explore

Get started Teams Realms Builder Browse teams Open builder View realms
Default realm personal is ready when you connect in Step 2. Open realm →
  1. 1

    Run locally

    Install the CLI, start cliqd, install a team, then init → assemble → run on your machine.

    1. 1.1

      Install the CLI

      curl -fsSL https://getcliq.io/cliq/install | bash
cliq --version
    2. 1.2

      Start the daemon (cliqd)

      Local authority process. Keep it running while you work.

      cliqd &
# optional: cliqd --help
    3. 1.3

      Install a team

      Install once per machine into the daemon catalog. What is a team?

      Browse teams 
      cliq team install @cliq/hello-world
# or: cliq team install file://./path/to/team.yml
    4. 1.4

      Init, assemble, run

      mkdir ~/cliq-hello && cd ~/cliq-hello
cliq init
cliq assemble @cliq/hello-world
cliq run
  2. 2

    Connect to Hub

    Log in from the CLI. Your personal default realm enroll token is issued with login — just (re)start cliqd to auto-enroll.

    1. 2.1

      cliq login

      Saves your Hub session and personal default realm. No separate mint step.

      cliq login
cliq whoami
    2. 2.2

      Start cliqd (auto-enrolls)

      cliqd imports your login session and enrolls on your default realm automatically. Realm tokens →

      Open personal 
      cliqd
# or restart if already running — session + default realm are picked up on boot
    3. 2.3

      Init, assemble, run

      Same local loop — daemons and runs show on your default realm overview.

      cliq init
cliq assemble @cliq/hello-world
cliq run
  3. 3

    Create your own realm

    For sharing: create a realm, invite users, mint enroll tokens for teammates, then init → assemble → run on each machine.

    1. 3.1

      Create realm, add users, share tokens

      Your personal default realm is already yours. Create another when you need a shared space — teammates need their own enroll tokens (unlike your login auto-enroll).

      Create realm Add users Share enroll tokens
    2. 3.2

      Init, assemble, run

      export CLIQ_DAEMON_TOKEN=cliq_dt_••••••••   # shared realm enroll token
cliqd
mkdir ~/shared-project && cd ~/shared-project
cliq init
cliq assemble @cliq/hello-world
cliq run

What you’ll use

cliqd
Local daemon. After cliq login, boot auto-enrolls on your default realm — no manual token mint.
Team
Install with cliq team install, then assemble in a workspace. Browse catalog
Realm
Machine access group. Default realm for Step 2; create your own in Step 3 to share.
Builder
Describe a team in plain English; generate roles, workflow, and gates. Open builder
